# Set up v0 in Pulse

Pulse shows your v0 billing allowance — the share of the cycle's balance used — and the API rate limit, each from a size and a remainder v0 reports.

## What you need

A v0 account and a v0 Platform API key.

## Steps

1. Open [v0.app/settings/keys](https://v0.app/settings/keys) and create or copy an API key.
2. In Pulse: **Settings → Accounts → v0**. Turn on **Show in panel**. Under **Connection**, paste the key into **API key** and click **Save**.
3. Within a few seconds the ring appears, and the pane lists the credit allowance and the message allowance, with the resets v0 reports.

## If it doesn't work

| Pulse says | What to do |
|---|---|
| Add an API key in Settings. | Paste a key from v0.app. |
| That key was refused. Check it in Settings. | Create a fresh key and paste it again. |
| The service didn't respond. / Checking too often — easing off. / The service returned an error. | A temporary network or server problem. Wait a moment and try again. |
| No limits reported. | v0 reported the allowance's size but not how much is left. |
| Couldn't read the reply. | v0 sent a billing type Pulse doesn't recognize. |

## What Pulse reads

Your key is stored encrypted on this Mac and sent only to v0's own API (`api.v0.dev`) when Pulse checks your usage.
