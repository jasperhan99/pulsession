# Alibaba Token Plan

Profiled provider: [`Sources/Pulse/Providers/Profiled/AlibabaTokenPlanUsageService.swift`](../../Sources/Pulse/Providers/Profiled/AlibabaTokenPlanUsageService.swift). User setup: [../setup/alibaba-token-plan.md](../setup/alibaba-token-plan.md).

- **Credential:** `.localLogin`. Pulse runs Alibaba's Bailian CLI (`bl`) through `BoundedProcess` (15 s, 256 KiB) with the login it already saved. Nothing is pasted, no file of `bl`'s is read or written, and no token is refreshed. CodexBar runs the same CLI; there is no file of `bl`'s to read instead.
- **Locating `bl`:** `PATH`, then `~/.local/bin`, `~/.npm-global/bin`, `~/.bun/bin`, `/opt/homebrew/bin`, `/usr/local/bin`. Not found → "Sign in with this service's own app or command-line tool first." (`.localLoginMissing`).
- **Environment:** `HOME`, `LANG`, `LC_*`, `TZ` and proxy variables only (Pulse's proxy setting applied), and a `PATH` that starts with `bl`'s own directory so a script's interpreter is found. Nothing else in Pulse's environment reaches `bl`.
- **Route:** `bl usage token-plan --console-region {ap-southeast-1|cn-beijing} --console-site {international|domestic} --output json`. International first, domestic second; no setting chooses, `requiresScopeMatch` is false. When both fail, an expired login is reported only if both said so.
- **Reply:** a flat object, or the console's envelope (`{ code, data: { DataV2: { data: { success, data: {…} } } }, successResponse }`, possibly with JSON strings inside), expanded first. The object holding `per5HourPercentage`/`per1WeekPercentage`/`per1MonthPercentage` is read.
- **Windows:** `per5HourPercentage` (5 h), `per1WeekPercentage` (7 d), `per1MonthPercentage` — a month, so 30 days is a sort key only (`reportsLength: false`). Resets from `per…ResetTime` (epoch ms); a reset is only taken for a window whose figure is there, and one in the past is dropped.
- **Figures:** the ratio as reported, 0…1. A figure above 1 is left off, as CodexBar does: the CLI's unit is not documented and a percentage would read a hundredfold. Negative, boolean or missing drops that window; none left is "No limits reported".
- **Exits:** non-zero with sign-in wording on stderr ("not logged in", "token expired", …) → `.localLoginExpired`; any other non-zero exit → "Couldn't read the reply." (a CLI too old for the command also exits non-zero, and a sign-in remedy would change nothing). Timeout → `.unreachable`. A console error in the JSON: sign-in wording → `.localLoginExpired`, other → `.serverError`.
- **Left out:** CodexBar also reads the console with a browser session: a Team plan's shared credit pool (`GetSubscriptionSummary`) and the Personal routes on `bailian-singapore-cs.alibabacloud.com` / `bailian-cs.console.aliyun.com`, on one of four sites/variants the reader picks. That needs a site/variant picker Pulse does not have, so a Team plan's credit pool is not shown. Older `bl` versions omit the monthly window; it is then absent, not guessed. The tier's credit totals (`quota-config`) have nowhere to be shown.
- **Evidence:** second-hand. The shape comes from CodexBar's Alibaba Token Plan provider and its tests (MIT); `bl` has not been run against a live account here. The fixture is `Tests/PulseTests/Fixtures/alibaba-token-plan-cli-usage.json`.
