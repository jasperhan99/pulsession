# Nous Portal

Profiled provider: [`Sources/Pulse/Providers/Profiled/NousPortalUsageService.swift`](../../Sources/Pulse/Providers/Profiled/NousPortalUsageService.swift). User setup: [../setup/nous-portal.md](../setup/nous-portal.md).

- **Credential:** `localLogin` — the OAuth access token Hermes Agent saved. Read from `~/.hermes/auth.json`, then `~/.hermes/shared/nous_auth.json`, in any of Hermes's three shapes (`providers.nous`, a `credential_pool.nous` list — the entry whose token lasts longest — or a bare state object with `access_token`). Nous API keys only authenticate inference and are refused by the account endpoint, so there is no key field.
- **Never refreshed.** The token lives about an hour; its refresh token is single-use and the portal revokes the whole session when an old one is replayed, so a second client refreshing would sign Hermes out. Pulse reads only `access_token`. A token whose `expires_at` (or, failing that, JWT `exp`) is within 60 s is not sent: `.localLoginExpired`. A 401/403 is also `.localLoginExpired`. No file with a token is `.localLoginMissing`.
- **Route:** `GET {portal}/api/oauth/account`, bearer token. `{portal}` is the file's `portal_base_url` only when it is https, on `nousresearch.com` or a subdomain, with no path, port or credentials; otherwise `https://portal.nousresearch.com`.
- **Reply:** `{ subscription: { plan, monthly_credits, credits_remaining, rollover_credits, current_period_end }, purchased_credits_remaining, paid_service_access: { subscription_credits_remaining, purchased_credits_remaining, total_usable_credits } }`. Amounts are finite numbers or decimal strings; anything else (a boolean, `"NaN"`, an empty string) makes the reply unreadable. No amount at all is unreadable. A top-level `error` is `.serverError`.
- **Window:** one, `.monthly`, only when `monthly_credits > 0` **and** `credits_remaining` is reported: used = `monthly − max(0, remaining)`, over `monthly`. A billing cycle, so 30 days is a sort key only (`reportsLength: false`); resets at `current_period_end`. A grant with no remainder, or no grant (free tier), draws no ring.
- **Balance:** `total_usable_credits`, or `purchased_credits_remaining` when no total is given, as USD (`creditRemaining`, `reportsSpendableBalance`). The reply carries no currency code; the portal prices credits in dollars.
- **Plan:** `subscription.plan`.
- **Left out:** `rollover_credits` (a detail with nowhere to go; it is read only to tell an empty reply from one with figures); `user.email` and `organisation.name` (identity, not usage); `HERMES_HOME`, `NOUS_PORTAL_ACCESS_TOKEN` and the portal-URL environment overrides CodexBar honours — a menu-bar app does not see a shell's environment.
- **Evidence:** second-hand. The shape comes from CodexBar's Nous provider (`NousSettingsReader`, `nous.ts`) and its tests (MIT); no live account has been read. Fixtures: `Tests/PulseTests/Fixtures/nous-portal-account.json`, `nous-portal-auth.json`.
