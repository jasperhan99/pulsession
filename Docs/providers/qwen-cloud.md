# Qwen Cloud

Profiled provider: [`Sources/Pulse/Providers/Profiled/QwenCloudUsageService.swift`](../../Sources/Pulse/Providers/Profiled/QwenCloudUsageService.swift). User setup: [../setup/qwen-cloud.md](../setup/qwen-cloud.md).

- **Credential:** `.sessionCookie(host: "qwencloud.com")`, keeping any one of `login_qwencloud_ticket`, `login_aliyunid_ticket`, `qwen_sso_ticket` (at least one required), and `login_current_pk`, `login_aliyunid_pk`, `login_aliyunid_csrf`, `csrf`, `cna`, `sec_token`. Requests go through an ephemeral session with no cookie jar and no redirects; a 3xx is an expired session.
- **Security token:** every gateway call carries the console's `sec_token`: scraped from `GET https://home.qwencloud.com/billing/subscription/token-plan-individual` (unless that is a sign-in page), else the `sec_token` cookie, else `GET https://home.qwencloud.com/tool/user/info.json`. None → "session expired", unless the page could not be reached (→ that reason).
- **Route:** `POST https://cs-data.qwencloud.com/data/api.json?action=IntlBroadScopeAspnGateway&product=sfm_bailian&api={api}&_v=undefined`, form body `product`, `action`, `sec_token`, `region=ap-southeast-1`, `language=en-US`, `params` (`{"Api","V":"1.0","Data":{…,"cornerstoneParam":{…,"consoleSite":"QWENCLOUD","X-Anonymous-Id":cna}}}`), CSRF from `login_aliyunid_csrf`/`csrf` as `x-xsrf-token`/`x-csrf-token`. Form fields are escaped to unreserved characters so `+`, `&`, `=` survive. `api` is `zeldaHttp.apikeyMgr./tokenplan/personal/api/v2/usage`, then `…/subscription` with `commodityCode=sfm_tokenplansolo_public_intl` for the tier name only (best-effort).
- **Reply:** the console's envelope, with JSON strings inside expanded first. Windows are read by the same reader as Alibaba Token Plan (`AlibabaTokenPlanUsageService.rollingWindows`): `per5HourPercentage` (5 h), `per1WeekPercentage` (7 d), `per1MonthPercentage` (a month, 30 days as sort key, `reportsLength: false`), each a ratio, resets from `per…ResetTime` (epoch ms; past → dropped). Tier from `specCode` (`lite`/`standard`/`pro`/`max` capitalized).
- **Figures:** the ratio as reported; negative or missing drops that window; none left is "No limits reported". An older summary-shaped reply with `TotalCount: 0` is "no plan".
- **Errors:** a frame with `success`/`successResponse` false, sign-in wording (`ConsoleNeedLogin`, `TokenError`, "refresh page", "请求已经过期"), or refusal wording (`NotAuthorized`, "forbidden", 401/403) → session expired. `Workspace.NotAuthorised` is a permission, not a session → "The service returned an error." A sign-in HTML page in place of JSON → session expired.
- **Left out:** `quota-config` (the tier's credit totals) — Pulse has nowhere to show them, and the ratio is already the service's own figure. CodexBar's fallback that reads credit totals from an older subscription-summary shape by guessing among many key names is not ported; only its "no subscriptions" count is honoured.
- **Evidence:** second-hand. The shape comes from CodexBar's Qwen Cloud and Alibaba Token Plan providers and their tests (MIT); CodexBar's own proof page records a live Pro-tier weekly reading. No live account has been read here. Fixtures: `Tests/PulseTests/Fixtures/qwen-cloud-*.json`.
